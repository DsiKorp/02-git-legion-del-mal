# 🦹‍♂️ Acerca de — La Legión del Mal

## ¿Qué es este proyecto?

Un repositorio de práctica de Git disfrazado de organización criminal ficticia.

Por fuera parece la wiki interna de una alianza de supervillanos. Por dentro es un proyecto técnicamente funcional con estructura de carpetas, flujos de trabajo, manejo de secretos y resolución de conflictos documentada.

La ficción es el envoltorio. La práctica es el contenido.

---

## 🎯 ¿Por qué existe?

Porque aprender Git con `hello-world` y `git init` aburre.

La motivación importa. Un repositorio temático te da:

- **Causa** — los commits no son por hacer, son parte de la historia.
- **Contexto** — cada archivo tiene un porqué narrativo.
- **Memorable** — recordarás la rama donde se rompió algo más fácil si la rama se llamaba `experiment/magneto-imanes`.
- **Humor** — los errores se documentan mejor cuando puedes culpar a Joker.

---

## 👥 ¿Para quién es?

- 🐣 **Reclutas novatos** que están aprendiendo Git por primera vez.
- 🛠️ **Equipos de educación** que necesitan un ejemplo práctico y divertido.
- 🎭 **Curiosos** que quieren ver un repo bien organizado con personalidad.
- 🦹 **Villanos retirados** que extrañan el oficio.

## 📜 Origen

La Legión nació como una broma interna para hacer el aprendizaje de Git más llevadero.

Lo que empezó como un `mkdir legion-del-mal` se convirtió en un espacio donde:

- Las prácticas reales de versionado conviven con nombres absurdos.
- Los conflictos se resuelven y se documentan (ver historial de commits).
- La documentación importa tanto como el código — quizá más.

---

## ⚠️ Una nota sobre el tono

Sí, es humor. No, no estamos planeando conquistar nada.

Pero todo lo técnico que ves aquí **funciona de verdad**:

- El `.gitignore` ignora archivos reales.
- Las convenciones de commits se aplican de verdad.
- Los secretos se manejan como secretos, no como chistes.

Si quieres tomar el repositorio como ejemplo de buenas prácticas, puedes. Si solo quieres pasarla bien leyendo sobre las aventuras de Lex Luthor, también.

## 🤝 Contribuir

¿Nuevo en la Legión? El proceso es simple:

1. Haz un fork o crea una rama.
2. Sigue las convenciones de `wiki.md`.
3. Documenta lo que hiciste.
4. Envía un PR. El Consejo revisará.

¿Encontraste un bug en una de nuestras operaciones? También es bienvenido.
